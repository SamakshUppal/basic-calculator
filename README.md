# Basic Calculator 🧮

This is a simple web-based calculator that performs basic arithmetic operations using HTML, CSS, and JavaScript.

## 🔧 Features
- Addition, Subtraction, Multiplication, and Division
- Responsive layout using CSS
- Simple and beginner-friendly UI
- Real-time calculation with JavaScript

## 📁 Project Structure
```
basic-calculator/
├── index.html
├── style.css
└── script.js
```

## 🚀 Getting Started

### 💻 To run locally:
1. Clone the repository:
   ```bash
   git clone https://github.com/SamakshUppal/basic-calculator.git
   ```
2. Open `index.html` in your browser.
